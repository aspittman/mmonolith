# Supplying evidence without inventing it

The discovery CLI supports the existing `--demand-file`, `--buyers-file`, and optional billed `--with-keywords`, plus `--quote-file` and `--assessment-file`. dsmonitor's daily launcher accepts corresponding `demand_file`, `buyers_file`, `quote_file`, `assessment_file`, and explicit `with_keywords:true` per topic. No billed lookup is enabled by default.

Quote exports are bounded JSON objects with `contract:registrar-checkout-quotes-v1`, the actual `organization_id`, matching `subject_key`, HTTPS `source_url`, `retrieved_at`, and at most 50 `quotes`. Each quote has `domain`, `provider:GoDaddy`, `price_type:checkout_total`, `currency:USD`, `status:available|unavailable`, `checked_at`, and numeric `acquisition_price`. Use an actual verified total, including applicable fees, with its source. This is an import contract, not a new live GoDaddy API integration. The decision policy still checks quote age and the acquisition cap. The legacy availability-file importer remains available but does not prove a GoDaddy checkout total.

Assessment exports have organization/subject/source/retrieval metadata and at most 50 `candidates`. Each candidate has `domain`, optional `decision_metrics` and optional `trademark_screening`. Supported score dimensions are commercial_intent, historical_performance, trend and brandability; each metric needs `value` (0–100), `source_reference`, and `observed_at`. Assessments must be honestly labeled and attributable; a normalized score is not a raw market measurement. Stale/future or unattributed metrics do not gain score points. A known trademark conflict vetoes acquisition investigation. An unknown screen is not legal clearance.

The new production review does not require predictions. `--learn` records linked review outcomes in the existing feedback ledger with `evaluation_kind:OUTCOME_REVIEW`, null prediction, `INSUFFICIENT_DATA`, and unchanged confidence. New research reports reference this feedback and surface missing evidence. Forecast evaluation continues unchanged for actual predictions. A reviewed gap remains a gap until new evidence arrives.
